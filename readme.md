# 📊 Employee Salary Analysis

A beginner Data Analysis project built with **Python**, **Pandas**, and **Matplotlib**.

This project analyzes employee salary data from a CSV file, performs statistical analysis, groups data by departments and cities, and visualizes the results using different charts.

---

## 🚀 Features

* Read employee data from a CSV file
* Analyze salary statistics
* Find the highest and lowest salary
* Calculate:

  * Total Salary
  * Average Salary
  * Number of Employees
* Group data by Department
* Group data by City
* Sort grouped results
* Create professional data visualizations

---

## 📊 Data Analysis

The project performs the following analyses:

### Salary Statistics

* Highest Salary
* Lowest Salary
* Average Salary
* Total Salary
* Total Number of Employees

### Department Analysis

* Total Salary by Department
* Average Salary by Department
* Number of Employees by Department

### City Analysis

* Total Salary by City
* Average Salary by City
* Highest Salary by City

---

## 📈 Data Visualization

The project includes:

* 📊 Bar Chart

  * Total Salary by Department
  * Departments highlighted using different colors based on salary totals

* 🥧 Pie Chart

  * Employee distribution by Department

* 📍 Scatter Plot

  * Relationship between Experience and Salary
  * Dynamic point colors and sizes based on salary
